# 资料服务接口

设备读取首帧要求继续读取，FCB=0 可重获首帧，FCB=1 获得末帧。推进来源后同一主地址换成另一设备；secondaryAddress 同步改变，旧续帧仍可作为迟到资料观察。

本地网关返回 EN 13757 常见长帧，校验和覆盖 C/A/CI 与用户数据。身份包括设备识别号、厂家、版本及介质，不能仅用主地址。/next?fcb=0 或 1 对应网关转交的帧计数位，0x1f 表示后续还有记录；厂家专用尾部按原字节保留。

本地服务的资料入口为 `/meter/1/read`。`fixtures/ordinary.json` 记录当前可预览的资料；`fixtures/transition.json` 保存资料源连续两个发布日期。调用 `POST /control` 并传入 `{"action":"advance"}` 推进发布日期，`inspect` 返回实际请求记录，`reset` 恢复本地源；控制入口不属于远端标准协议。来源分段、延迟和断连均可用场景条目的 `chunks`、`delayMs`、`disconnect` 配置，不需要依赖实际网络故障。

`fixtures/ledger.json` 另提供 `/meter/2..5/read` 的有状态网关：帧计数位不变时重发当前帧，翻转时给出下一帧。表 2 有三帧，覆盖存储号、费率、多种单位、特殊 BCD、厂家专用记录与尾部，推进后整表更换；表 3 的续帧永远是重发；表 4 首次续帧断连，推进后同样换表；表 5 的续帧身份与首帧不一致。各表 `identity` 字段经 `/meter/<n>/identity` 提供。

原件目录采用内容摘要寻址，接收凭据独立记录来源、媒体类型和预览结果。单份资料接收不表示来源范围已经读完，也不推断缺失资料的业务含义。
